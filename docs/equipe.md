## Processo e Organização da Equipe

- **Comunicação interna**: Grupo de WhatsApp/Discord para alinhamentos diários e resolução de impedimentos.
- **Gestão de Tarefas**: GitHub Projects com quadro Kanban (To Do, In Progress, Review, Done).
- **Fluxo de Trabalho Git**:
  - A branch `main` permanecerá protegida e sempre estável.
  - O desenvolvimento de cada desafio ocorrerá em branches dedicadas (ex: `desafio-01`, `desafio-02`).
  - Todo código integrado passará por Pull Requests (PR) obrigatoriamente aprovados com o pipeline de CI verde.
- **Reuniões de Alinhamento**:
  - Reunião rápida quinzenal pré-entrega para revisão geral dos entregáveis.
